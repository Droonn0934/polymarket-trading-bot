# Polymarket Trading Bot CLI (Gamma API)

Консольный торговый бот на Python для децентрализованной платформы предсказаний Polymarket (работает через Gamma API / CLOB). Спроектирован с разделением на симуляционный режим (PAPER) и реальную торговлю (LIVE), а также оснащен адаптивным планировщиком для высокочастотного мониторинга в пиковые моменты.

## 🚀 Основной функционал

* **Адаптивный планировщик (APScheduler):** В обычном режиме бот опрашивает внешний API по заданному расписанию (настраиваемые минуты часа). При приближении к целевым меткам бот переходит в **высокочастотный пиковый режим** (интервал опроса стакана до 1-2 секунд).
* **Парсинг локальных триггеров:** Бот динамически считывает текстовый файл конфигурации (`triggers.txt`), фильтрует условия (актуальная дата, исход `YES`/`NO`, пороговая цена) и берет в работу только целевые маркеры.
* **Два режима исполнения:**
  * `PAPER` — Безопасное тестирование стратегий. Бот парсит доступную ликвидность в стакане и имитирует сделки, записывая результаты в локальный лог-файл (`paper_ledger.log`).
  * `LIVE` — Реальная торговля. Подписание транзакций приватным ключом кошелька и выставление жестких лимитных ордеров через официальный клиент `py-clob-client`.
* **Безопасность:** Чувствительные данные (приватные ключи, адреса кошельков) изолированы в файле переменных окружения `.env`.

## 🛠 Стек технологий

* **Язык:** Python 3.10+
* **Планировщик:** APScheduler (Advanced Python Scheduler)
* **Работа с API & Web3:** `py-clob-client` (Polymarket), Requests
* **Конфигурация:** Python-Dotenv

## 📂 Структура проекта

* `bot.py` — Основная логика планировщика, парсинга внешних данных и обработки триггеров.
* `triggers.txt` — Текстовый файл с входными параметрами для торговых стратегий.
* `.env` — Конфигурационный файл для безопасного хранения API-ключей и переключения режимов.
* `paper_ledger.log` — Лог-файл симуляционных сделок (генерируется автоматически в режиме PAPER).
